# 도미노 경제 · 2023 산업연관표 파급 게임

한국은행 **2023년 산업연관표(연장표)** 의 생산자가격 투입산출표를 이용해, 한 산업의 수요·국산화·원가 변화가 경제 전체로 번지는 과정을 게임처럼 체험하는 정적 웹앱입니다. 서버 없이 GitHub Pages에서 바로 동작합니다.

## 실행 방법

- 배포 주소에 접속하면 됩니다. 로컬에서 보려면 폴더를 웹서버로 열거나(예: `python -m http.server`), 상단 **내 PC 파일 업로드** 버튼으로 컴퓨터에 있는 투입산출표 `.xlsx` 파일을 직접 선택해 실행할 수 있습니다.
- 상단 **분류**에서 대분류(33) · 중분류(83) · 소분류(165) · 기본부문(380) 중 하나를 고르고 **엑셀 자료 불러오기**를 누르거나, **내 PC 파일 업로드**로 원하는 분류의 엑셀 파일을 바로 올리면 부문 수를 자동 인식합니다.

## 게임 방법

1. **파급 게임** 탭에서 산업 타일을 누릅니다. 타일 색이 진할수록 생산유발 효과가 큽니다. 검색창으로 산업을 찾을 수 있습니다.
2. 모드를 고릅니다.
   - **수요 투입**: 선택한 산업의 최종수요(1~10조 원)가 생산·부가가치·수입을 얼마나 유발하는지 계산합니다.
   - **국산화**: 선택한 산업이 쓰는 수입 중간재를 α%만큼 국산으로 바꿨을 때의 추가 생산과 수입 절감을 계산합니다.
   - **원가 충격**: 선택한 산업의 원가가 1~30% 오를 때 다른 산업의 물가 파급을 계산합니다.
3. **도미노 쓰러뜨리기**를 누르면 상단 연쇄 도미노 무대와 산업 타일 보드에서 파급이 큰 산업부터 도미노가 차례로 쓰러지며, 결과 카드와 해설이 나옵니다.
4. 실행할 때마다 XP를 얻고, **미션** 탭의 5개 미션(생산 파워, 부가가치 장인, 국산화 챔피언, 누출 제로, 도미노 연쇄)을 달성하면 보너스를 받습니다. 진행 상황은 브라우저에 저장됩니다.

**데이터 탐색** 탭에서는 시트별 행렬(국산투입계수, 수입투입계수, 총투입계수, 생산유발계수)을 전환하며, 선택한 산업의 투입 구조를 크기순으로 보고 행 산업을 검색할 수 있습니다.

## 분석 방법

국산 기준 레온티에프 모형을 사용합니다. 한국은행이 생산유발계수를 산출하는 방식과 같습니다.

- **생산유발**: `x = (I − Ad)⁻¹ f`. Ad는 국산투입계수 행렬, f는 최종수요, x는 부문별 총산출입니다. 부문 j의 생산유발계수는 `(I − Ad)⁻¹`의 j열 합입니다.
- **부가가치·수입 유발**: 부가가치율 `vⱼ = 1 − Σᵢ(Adᵢⱼ + Amᵢⱼ)`, 수입의존도 `mⱼ = Σᵢ Amᵢⱼ`로 계산해 `Σ vᵢxᵢ`, `Σ mᵢxᵢ`를 구합니다.
- **국산화 효과**: 산업 k의 수입 중간재 α를 국산으로 바꾸면 Ad의 k열이 `u = α·Am·k`만큼 바뀝니다. 역행렬을 다시 구하지 않도록 Sherman–Morrison 공식 `x′ = x + L·u·(Lkk·F)/(1 − Σⱼ Lkⱼ uⱼ)`를 씁니다.
- **원가 충격**: 충격 산업의 가격을 고정하고 `pⱼ = Σᵢ Aᵢⱼ pᵢ`(A = Ad + Am)를 반복 계산합니다.

## 단위

- 금액: **백만 원**(생산자가격, 2023년 당해년 가격). 화면에서는 억·조 단위로 환산해 표시합니다. 1조 원 = 1,000,000백만 원.
- 계수: 무차원. 생산유발계수는 배(倍)로 표시합니다.
